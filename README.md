# 全景查看器

在浏览器里查看本机的等距圆柱全景图。双击 `启动查看器.bat`，或在本目录执行 `node server.js`。服务只监听 `127.0.0.1`，从 4173 起找空闲端口，并自动打开浏览器。

需要本机已安装 Node.js。有 ffmpeg 时，大图会先缩成预览再显示；没有则直接发送原图。

顶部输入文件夹路径后点「打开」。拖动时画面跟着指针走，滚轮缩放。方向键或 `W` `A` `S` `D` 环视，`N` / `P` 换图，空格自动旋转，`F` 全屏，`R` 重置。

换一台电脑时，把全景图目录作为参数传入：

```bat
node server.js "D:\你的全景目录"
```

不要把全景图放进这个仓库。继续改程序前先读 [AI交接.md](AI交接.md)。
